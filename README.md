# elementary_school_app

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A simple web application for elementary school students. It features a home screen with app icons for a calculator and a TWICE-themed activity center.

## Demo

The application is hosted on GitHub Pages:
**https://github.com/code4fukui/elementary_school_app

## Features

*   **Home Screen (`index.html`)**: A simple, icon-based launcher for accessing the different apps. Several placeholder icons ("更新待ち" - *Awaiting Update*) are included for future expansion.
*   **Calculator (`app/calculator.html`)**: A clean, functional calculator for basic arithmetic operations, including addition, subtraction, multiplication, division, percentages, and parentheses.
*   **TWICE App (`app/twice.html`)**: An application dedicated to the K-pop group TWICE, featuring separate sections for a game and album information.

## Usage

To run the application locally, clone the repository and open the `index.html` file in a web browser.

```bash
git clone https://github.com/code4fukui/elementary_school_app.git
cd elementary_school_app
# Open index.html in your browser
```

From the home screen, click an icon to launch the desired application.
