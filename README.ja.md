# elementary_school_app

小学生向けのシンプルなWebアプリケーションです。ホーム画面には、計算機とTWICEをテーマにしたアクティビティセンターのアプリアイコンが配置されています。

## デモ

本アプリケーションはGitHub Pagesでホストされています:
**https://github.com/code4fukui/elementary_school_app

## 機能

*   **ホーム画面（`index.html`）**: 各アプリにアクセスするための、シンプルでアイコンベースのランチャーです。将来の拡張に向けて、いくつかのプレースホルダーアイコン（「更新待ち」）が含まれています。
*   **計算機（`app/calculator.html`）**: 足し算、引き算、掛け算、割り算、パーセント、括弧などの基本的な四則演算ができる、すっきりと機能的な計算機です。
*   **TWICEアプリ（`app/twice.html`）**: K-POPグループ「TWICE」専用のアプリで、ゲームとアルバム情報のセクションが分かれています。

## 使い方

アプリケーションをローカルで実行するには、リポジトリをクローンし、Webブラウザで`index.html`ファイルを開きます。

```bash
git clone https://github.com/code4fukui/elementary_school_app.git
cd elementary_school_app
# Open index.html in your browser
```

ホーム画面からアイコンをクリックすると、目的のアプリが起動します。
